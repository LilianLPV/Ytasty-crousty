# Ytasty Crousty — Backend

API REST de gestion des commandes pour **Ytasty Crousty** (restaurants située à Aix, Lyon et Paris).

---

## Stack techinque 

| Domaine | Technologie |
|---|---|
| Langage | Python 3.11+ |
| Framework API | FastAPI |
| Validation | Pydantic v2 |
| ORM | SQLAlchemy 2.0 |
| Base de données | PostgreSQL 16 |
| Authentification | JWT (python-jose) + hachage bcrypt (passlib) |
| Conteneurisation | Docker / Docker Compose |

---

## Prérequis
 
Avant de lancer le projet, assure-toi d'avoir installé :
 
- [Python 3.11+](https://www.python.org/downloads/)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) (doit être **lancé** avant de démarrer)
- [Git](https://git-scm.com/)
